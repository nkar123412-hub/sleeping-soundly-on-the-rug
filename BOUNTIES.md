# Chapter Bounties

The bounty program is designed to make the guide better while helping readers build a predictable contribution habit.

No amount is promised in this file. Payout amount, token/cash mix, eligibility, and sponsor are set per GitHub issue or external bounty page.

## Bounty rule zero

Do not manufacture hype. Useful work only.

## Submission standards

A bounty submission must include:

1. the chapter/issue it addresses,
2. the specific improvement made,
3. screenshots or links where relevant,
4. sources for factual claims,
5. a short note on what could still be wrong,
6. no private keys, seed phrases, client data, or secrets.

## Bounty ladder

### Chapter 1 — Wallets and the financial floor

Eligible work:
- clearer wallet setup checklist,
- seed phrase safety diagram,
- glossary improvements,
- beginner confusion notes from a real reader,
- localized translation,
- short screen-recording script for wallet setup without exposing secrets.

Acceptance bar:
- makes beginners safer,
- includes financial-health-first disclaimer,
- never asks for or displays seed phrases,
- does not recommend buying a token.

### Chapter 2 — Bounties before bags

Eligible work:
- bounty-evaluation checklist,
- scam-pattern examples,
- submission template,
- list of reputable bounty platforms with caveats.

### Chapter 3 — Hermes companion setup

Eligible work:
- installation guide improvements,
- crypto-safety prompt pack,
- agent refusal examples around seed phrases and investment advice,
- test cases for unsafe prompts.

### Chapters 4-12

Each later chapter bounty follows the same pattern:

- explain the concept more safely,
- add receipts,
- add diagrams,
- add beginner tests,
- add agent prompts,
- add miss logs.

## Maintainer review rubric

We accept work that increases:

- beginner safety,
- factual accuracy,
- receipt quality,
- clarity,
- reproducibility,
- humility under uncertainty.

We reject work that increases:

- hype,
- trading pressure,
- unverifiable claims,
- seed phrase exposure risk,
- fake certainty,
- decorative complexity.

The universe is already mostly hostile. Our documentation does not need to help.
